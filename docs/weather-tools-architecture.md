# 天气数据可信度与可扩展工具架构

审查日期：2026-08-03

## 结论

霁光使用可信的开放数值预报来源，但它不是权威实况或灾害预警系统。服务端通过 HTTPS 调用 Open-Meteo，明确选择 ECMWF IFS 0.25° 与中国气象局 CMA GRAPES Global 15 km 两个独立模式，并通过 CAMS 获取气溶胶与 PM₂.₅。Open-Meteo 是聚合、重采样和 API 交付层；底层模式分别来自 ECMWF、中国气象局和 Copernicus。

这种组合适合机位筛选与天气机会分析，原因是来源公开、模式身份明确、可以对比模式分歧，并且响应字段和许可有公开文档。它不能替代观测站、天气雷达、临近预报或中国气象局灾害预警。

## 信任与许可边界

| 层级 | 当前使用 | 能证明什么 | 不能证明什么 |
| --- | --- | --- | --- |
| 数值模式 | ECMWF IFS 0.25°、CMA GRAPES Global 15 km | 独立机构的网格化未来天气指导；可比较云、雨、风等模式分歧 | 具体机位此刻的实况、街区级对流位置 |
| 大气成分 | CAMS 全球预报 | 气溶胶光学厚度与 PM₂.₅ 的大尺度背景 | 街区污染源或现场能见度实测 |
| API 交付 | Open-Meteo HTTPS API | 统一字段、时区、高程和模型选择；数据采用 CC BY 4.0 并要求归属 | 政府预警权威性或免费端点的商业使用权 |
| 天文几何 | Astronomy Engine | 日月高度、方位、暮光和食象几何 | 山体/建筑遮挡和天气实况 |
| 权威预警 | 当前仅提供中国气象局预警链接 | 用户可转到正式预警来源复核 | 工作台目前不会主动同步或推送预警 |

Open-Meteo 的开放端点适用于非商业使用并有公平调用限制。若部署属于商业用途，应配置 `OPEN_METEO_API_KEY`；霁光会同时切换到 `customer-api.open-meteo.com` 与 `customer-air-quality-api.open-meteo.com`。不能把“无需密钥”理解为“可以无条件商业使用”。

## 一页式工具系统

```text
共享状态：坐标 + 日期 + 数据生成时间
        │
        ▼
 /api/forecast：双模式天气 + CAMS + 天文几何
        │
        ├── 摄影计算器：霞光、雾景、日月、星空、食象
        └── 天气计算器：云层、降雨、彩虹潜势
                         │
                         ▼
工具注册表 ──► 同一地图 / 七天带 / 检查器 / 来源披露
```

用户只需选择一次位置。工具注册表中的十个工具共享当前坐标和日期；切换工具不会换页、打开模态框或重新请求天气。地图落点或日期变化后，全部工具使用同一份 168 小时响应同步更新。桌面端使用左侧工具轨，移动端使用可横向滚动的同一工具轨。

每个工具由三部分组成：

1. 注册信息：稳定 ID、所属工具族、名称、简写、说明和图标。
2. 纯计算器：从已经验证的提供方字段生成逐日代表窗口、0–100 信号、输入置信和模式分歧。
3. 面板渲染器：只负责该工具特有的解释；位置、日期、现场简报、来源和错误恢复由工作区统一提供。

因此新增雷暴、风、雪或空气质量工具时，不应增加页面路由或复制位置选择器。新增项进入同一个注册表、服务端计算集合和检查器插槽，现有地图、时间带、响应式布局、无障碍和覆盖核对会自动把它纳入审计。

检查器的 UI 也有稳定插槽契约，而不是每加一个工具就向下堆卡片：主结论、快速指标、逐小时趋势、方法边界与现场简报占满网格宽度；层次剖面、贡献因素和模式一致性使用可并排的微型图表。521px 以上为两列，520px 以下为单列。长解释进入可聚焦 hint，重要的方法限制则保留可见标题并渐进展开。新增工具应优先复用这些角色，仅在确有新型专业关系时增加可视化组件。

## 三个新增计算器

### 云层分析

- 使用总云量与低、中、高三层云量。
- 七天带显示每天峰值总云量；检查器显示峰值时刻、垂直结构、完整逐小时剖面和两个模式的峰值差异。
- 分数就是云量百分比，不解释为“好天气”或摄影成功率。

### 降雨分析

- 使用降水概率、总降水、连续性雨、阵雨和 WMO 天气代码。
- CMA 当前不提供 `precipitation_probability`。缺失值保持为空；计算器用明确的小时降水量形成“综合降水信号”，界面不会把它伪装为统计概率。
- 0–100 表示跨模式信号强度；实际雨量仍以 mm/h 单独展示。

### 彩虹潜势

- 要求同一网格小时存在降水/阵雨、直射太阳辐射和地平线上低于约 42° 的太阳。
- 建议观察方向是太阳方位加 180°，即反太阳方向。
- 单点模式无法知道雨幕是否真的位于观察者前方，因此只能称“彩虹潜势”。输入置信上限设为 70，界面始终显示空间限制说明。

## 扩展验收契约

新增工具必须同时提供：纯函数极端条件测试、双模式与单模式降级测试、API 合同断言、七天选择、地图落点更新、移动/桌面 Axe 扫描、八视口截图和注册表计数核对。`npm run verify:audit` 会在工具注册表、Playwright 流程或截图矩阵不一致时失败。
