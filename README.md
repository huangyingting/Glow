# 霁光 PRO · 风光摄影天气地图

霁光是一个地图优先的风光摄影决策工作台。用户可以搜索城市、使用浏览器定位，或直接在中国地图上点击/拖动观测点；系统会为该坐标重新获取 168 小时专业气象数据，并计算霞光、雾景、太阳、月亮、星空和食象摄影窗口。

## 当前摄影场景

- 朝霞 / 晚霞：低、中、高分层云量、降水、湿度、能见度、气溶胶和双模式一致性。
- 雾景潜势：露点差、相对湿度、低云、能见度、风速与非降水信号；因为尚未接入精细地形和水面距离，不把结果称为确定性的平流雾预报。
- 日出 / 日落：蓝调、黄金时段、日照长度、日出日落方位线。
- 月相 / 月升：按所选日期和当晚最佳小时计算照明、月相、月升月落、高度、方位与双模式天气机会，不再复用“当前月亮”。
- 星空 / 夜景：天文黑夜、三层云量、月光、降水、结露、能见度与阵风共同评分；明确不包含光污染、地形地平线和银河构图。
- 月食：为定位点搜索下一次峰值位于地平线上的食象及开始、食甚、结束时间。
- 日食：本地遮掩比例、太阳高度和接触时间；界面包含太阳滤镜安全提示。

专业变量被压缩为地图、七天机会带和右侧检查器：默认先给结论，随后是云层剖面、逐小时气象图、关键贡献、模式分歧和与拍摄时刻对齐的现场简报。简报包含阵风、来风方向、露点差、气压和海拔。食象不再伪装成七个相同的日分数，而是显示唯一事件、距离与是否进入天气预报窗口。切换场景不会离开地图或丢失观测点。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。天气默认通过 Open-Meteo 接入 ECMWF、CMA 和 CAMS，无需在浏览器中配置密钥。地图由 MapLibre GL 渲染，默认使用 CARTO / OpenStreetMap 栅格底图；可用 `NEXT_PUBLIC_MAP_STYLE_URL` 更换 MapLibre 样式。

## 验证

```bash
npm run verify
```

验证链路包含 ESLint、TypeScript、13 个气象/天文模型测试、生产构建，以及 14 个 Playwright 浏览器流程。浏览器审计会覆盖真实天气 API、全部七种摄影场景、七个日期、逐日月亮变化、城市搜索与键盘操作、两种定位入口、地图点击/标记拖动/平移/缩放/归属信息、数据披露、失败恢复，并在 320×568 到 1920×1080 的八种代表性视口生成 163 张状态截图。截图写入 `test-results/ui-audit/`，用于逐帧检查溢出、遮挡、可读性与交互反馈。

## 数据与概率边界

- ECMWF IFS 和 CMA GRAPES 分别评分；分歧越大、预报越远，置信度越低。
- CAMS 提供气溶胶光学厚度和 PM₂.₅。
- Astronomy Engine 根据定位点计算太阳、月亮与食象几何；天文事件可长期计算，但长期天气不可预测。
- 霞光、雾景、月亮和星空的 0–100 是透明的启发式“机会指数”，还不是由大量实拍样本校准的统计概率。
- 地图方位未计入山体/建筑遮挡；雾景尚未计入水体距离和精细地形；星空尚未计入光污染和银河构图。

完整数据调研见 [`docs/data-research.md`](docs/data-research.md)，摄影专业审查、缺口矩阵与实施路线见 [`docs/professional-photography-audit.md`](docs/professional-photography-audit.md)。

## 结构

- `components/weather-map.tsx`：MapLibre 生命周期、可拖动落点、太阳/月亮方位线。
- `components/glow-dashboard.tsx`：七种摄影场景、七天时间带、食象事件带和拍摄时刻现场简报。
- `lib/weather.ts`：双模式 168 小时数据、事件窗口和降级处理。
- `lib/glow-model.ts`：霞光机会模型。
- `lib/photography-models.ts`：雾景、月亮和星空机会模型。
- `lib/astronomy.ts`：蓝调/金色/天文暮光、逐日月相、月升月落及本地可见食象。
- `app/api/forecast/route.ts`：中国坐标校验、定位点私有缓存与统一 API。
