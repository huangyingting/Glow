# 霁光 PRO · 风光摄影天气地图

霁光是一个地图优先的风光摄影决策工作台。用户可以搜索城市、使用浏览器定位，或直接在中国地图上点击/拖动观测点；系统会为该坐标重新获取 168 小时专业气象数据，并计算霞光、雾景、太阳和天文摄影窗口。

## 当前摄影场景

- 朝霞 / 晚霞：低、中、高分层云量、降水、湿度、能见度、气溶胶和双模式一致性。
- 平流雾 / 雾景：露点差、相对湿度、低云、能见度、风速与非降水信号；因为尚未接入精细地形和水面距离，界面明确称为“雾景潜势”。
- 日出 / 日落：蓝调、黄金时段、日照长度、日出日落方位线。
- 月相 / 月升：照明比例、月相、月升月落、当前高度和方位线。
- 月食：为定位点搜索下一次峰值位于地平线上的食象及开始、食甚、结束时间。
- 日食：本地遮掩比例、太阳高度和接触时间；界面包含太阳滤镜安全提示。

专业变量被压缩为地图、七天机会带和右侧检查器：默认先给结论，随后是云层剖面、逐小时气象图、关键贡献和模式分歧。切换场景不会离开地图或丢失观测点。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。天气默认通过 Open-Meteo 接入 ECMWF、CMA 和 CAMS，无需在浏览器中配置密钥。地图由 MapLibre GL 渲染，默认使用 CARTO / OpenStreetMap 栅格底图；可用 `NEXT_PUBLIC_MAP_STYLE_URL` 更换 MapLibre 样式。

## 验证

```bash
npm run verify
```

验证链路包含 ESLint、TypeScript、9 个气象/天文模型测试、生产构建，以及真实天气 API、地图落点、全部六种摄影场景、城市/日期控制和 390px 手机端浏览器流程。

## 数据与概率边界

- ECMWF IFS 和 CMA GRAPES 分别评分；分歧越大、预报越远，置信度越低。
- CAMS 提供气溶胶光学厚度和 PM₂.₅。
- Astronomy Engine 根据定位点计算太阳、月亮与食象几何；天文事件可长期计算，但长期天气不可预测。
- 霞光和雾景的 0–100 是透明的启发式“机会指数”，还不是由大量实拍样本校准的统计概率。
- 地图方位未计入山体/建筑遮挡；雾景尚未计入水体距离和精细地形。

完整调研与未来校准路径见 [`docs/data-research.md`](docs/data-research.md)。

## 结构

- `components/weather-map.tsx`：MapLibre 生命周期、可拖动落点、太阳/月亮方位线。
- `components/glow-dashboard.tsx`：六种摄影场景、七天时间带和高密度检查器。
- `lib/weather.ts`：双模式 168 小时数据、事件窗口和降级处理。
- `lib/glow-model.ts`：霞光机会模型。
- `lib/photography-models.ts`：雾景机会模型及后续场景扩展入口。
- `lib/astronomy.ts`：太阳时段、月相、月升月落及本地可见食象。
- `app/api/forecast/route.ts`：中国坐标校验、定位点私有缓存与统一 API。
